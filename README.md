Osmida is a service marketplace and multi-portal inspection lead management platform built with Next.js, Supabase, and automated workflow pipelines.

---

## ✨ Features

- **Multi-Tenant Portals:** Separate, secure interfaces for Customers, Service Partners, and System Administrators.
- **Dynamic Service Selection:** Location-aware service catalog and interactive inspection selection modals.
- **Lead Intake Pipeline:** Seamless booking flows for property inspections, quotes, and service requests.
- **Role-Based Access Control (RBAC):** Row-Level Security (RLS) policies implemented via Supabase Auth.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js 14 (App Router), React, Tailwind CSS, TypeScript
- **Backend & Database:** Supabase (PostgreSQL, Auth, Row Level Security)
- **Deployment:** Vercel
